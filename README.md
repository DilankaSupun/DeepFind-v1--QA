# DeepFind Quality Assurance (QA) Repository

This repository contains the Quality Assurance (QA) documentation and testing assets for the DeepFind project.

## Overview

This repository serves as a centralized location for all testing and quality assurance materials. It includes bug reports, test cases, and test results used to ensure the reliability and functionality of the application.

## QA Process and Timeline

*   **Bug Reporting**: The bug report (`DeepFind_Search_Function_BugReport.pdf`) was created using **Notion**. This bug tracking and reporting process was conducted **concurrently while development was happening** to provide immediate feedback to the development team.
*   **Test Cases and Results**: The formal test cases (`DeepFind-Test Cases.pdf`, `DeepFind-Test Cases.xlsx`) and the final test results (`DeepFind-Final_Test_Cases.pdf`) were designed and executed **after the development phase was finished** to comprehensively validate the final build.

## Included Files

*   `DeepFind_Search_Function_BugReport.pdf`: Bug report generated during development.
*   `DeepFind-Test Cases.xlsx`: Excel spreadsheet containing the detailed test cases.
*   `DeepFind-Test Cases.pdf`: PDF version of the test cases.
*   `DeepFind-Final_Test_Cases.pdf`: Document detailing the final test execution results.
